## 探究一覧 — `app/(tabs)/explorations.tsx`（v2）

v1 に加え:

- カードに見取り図サムネ（あれば）
- `stale` 時: 「見取り図を更新できます」系の軽い促し
- 振り分け CTA: 「新しい問いを振り分ける」／二次「束を組み直す」
- 探究0: 見本プレビュー（束＋見取り図サンプルのカルーセル可）
- 非同期中: pending 表示（閉じてもよい旨）

## 探究詳細 — `app/exploration/[id].tsx`（v2）

縦の顔:

1. **見取り図**（あれば／pending／stale／生成 CTA）
2. synthesis（示唆）
3. 進行度
4. **問いの地図**
5. 問いリスト（切り口）

- 見取り図なし: 生成ボタン＋所要の一言
- pending: 待ちプレースホルダ
- stale: 現行画像を残しつつ際立つ「更新」
- 再生成前: 確認ダイアログ
- 長押し等で端末保存可
- チップナビで見取り図／地図／問いへジャンプしてよい（実装済み方針に合わせる）
