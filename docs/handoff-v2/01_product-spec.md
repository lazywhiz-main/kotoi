# 01 — 製品仕様（v2）

> ベース: `cursor-handoff/01_product-spec.md`  
> **v2 追加**: 体験②に **見取り図** を正式追加。

## 一行
雑多に放り込むと、AIが分類し・要約し・調べ、そして「次の問い」を返す個人用ノート。差別化は**問いの生成**。

## コアループ
```
Capture（放り込む） → Classify（分類） → Branch（memo / video で分岐）
  → Enrich（要約・調査） → Generate Questions（5類型の問い） → Store & Resurface（貯めて再浮上）
```

## 問いの5類型（全生成でこの枠を強制）
| キー | 類型 | 何を問うか |
|---|---|---|
| `dig` | 深掘り | なぜ・どう成り立つか、前提は何か |
| `con` | 接続 | 過去メモ・他領域とどう繋がるか |
| `ref` | 反証 | 本当にそうか、逆はどうか |
| `act` | 行動 | だから何をするか |
| `exp` | 拡張 | もし〜ならどうなるか |

## メモの分類（type）
ドメインではなく**処理の意図**。`task` は問いを作らない。`feeling` は分析・反証せず軽い振り返りのみ。

## 2つの体験

### 体験① 1メモの中＝育つスレッド
ルートメモを起点に要約・問い・追記／調べる／深掘りがぶら下がる1本のスレッド。  
挙動の真実: `mocks/mock_thread_v3.html`

### 体験② 溜まった後＝横断
| 要素 | 役割 |
|------|------|
| **問いの棚** | 未回答の問いを横断一覧・類型フィルタ |
| **探究** | 似たメモ・問いの束。synthesis（示唆）＋進行度 |
| **問いの地図** | 構造図（中心=探究、まわり=切り口、外側=問い） |
| **見取り図** | 探究の**一枚絵**（グラレコ的）。地図とは別物。お土産・愛着・コストあり |
| **今週のふりかえり** | 横断サマリー＋くり返しテーマ＋呼び戻し |

挙動の真実: `mocks/mock_accumulate_v1.html` ＋ 見取り図は `mocks/graphic-rec/` と実装済み詳細画面。

#### 見取り図と問いの地図の違い（重要）

| | 問いの地図 | 見取り図 |
|--|-----------|----------|
| 何か | 構造・ナビ用の図 | 意味の一枚絵（比喩・物語・空間など） |
| 生成 | クライアント描画（SVG） | AI（プロンプト設計＋画像生成）・承認／手動 |
| 更新 | メンバー変更で即反映 | 束が変わっても**勝手に描き直さない**（`stale`） |
| コスト | ほぼゼロ | 相対的に高い（日次上限の対象） |

詳細企画: [`07_graphic-rec.md`](./07_graphic-rec.md)

## ハイブリッド自動化
- 自動: 分類・要約・文字起こし・問い生成
- 承認／手動: 調べる・深掘り・**見取り図生成**・長尺動画・重い処理
- 日次コスト上限（`usage_ledger`）

## スコープ
- **Phase 1（MVP）**: Capture／スレッド／分類・要約・問い
- **Phase 2**: エージェント／問いの棚／探究・地図／ふりかえり
- **Phase 2+（v2）**: **見取り図**、振り分けの増分／stale、非同期待ち＋プッシュ
- **やらない（初期）**: 共有コラボ、複雑な同期、音声／画像入力（見取り図の**出力**画像は除く）
