最終更新: 2026-07-24  
ASC の **App Review Information → Notes** に貼る。

## Notes（英語でも可・下記は日本語）

```
【到達型トライアルについて】
本アプリは到達型トライアルを採用しています。通常、探究の見取り図を1枚受け取ったあと、2枚目を作成しようとしたときにペイウォールが表示されます。

【ペイウォールへの最短手順（審査用）】
1. 提供するデモアカウントでログイン
2. 下部タブの「設定」を開く
3. 「プラン」セクションの「プランを見る」または「続ける」をタップ
→ サブスクリプションの購入画面（ペイウォール）が開きます

【サンドボックス購入】
ペイウォールで年払い／月払いを選び、Sandbox Apple ID で購入を検証できます。
「購入を復元」も同画面にあります。

【自動更新・法的表示】
ペイウォール下部に、自動更新の説明および利用規約・プライバシーポリシーへのリンクがあります。
- Terms: https://kotoi.art/terms
- Privacy: https://kotoi.art/privacy

【通常フロー（任意）】
メモを数件投入 → 探究が立つ → 見取り図を1枚生成 → 別探究で見取り図を再度作成しようとするとペイウォールが出ます。
```

デモアカウントの ID / パスワードは Notes の別欄（Sign-in required）に記入。seed 手順は [`sample-account-seed.md`](../sample-account-seed.md)。

## 提出前チェック（課金）

- [ ] ASC のサブスク商品（月・年）が **提出準備完了**（表示名・価格・ローカライズ）
- [ ] アプリバイナリと **同じ審査セット** にサブスクが含まれる
- [ ] ペイウォールに自動更新文＋利用規約／PP リンクがある（実装済み）
- [ ] 表示価格が StoreKit / RevenueCat から取れている（ハードコードしない）
- [ ] Review メモに上記手順を貼った
