# KOTOI — AI コスト整理（プライシング研究用）

最終更新: 2026-07-10（§5 体験ベース頻度を追加）  
目的: 有料プラン設計のための**原価（COGS）**の材料。実測は `usage_ledger`、概算は本ドキュメントとコード内定数を参照。

---

## 1. コストの全体像

KOTOI の変動費はほぼ **AI API** のみ。インフラ（Supabase・Storage・Push）は固定費寄りで、ユーザー数が少ない間は AI が支配的。

```
ユーザー操作
  → Edge Function（Anthropic / OpenAI）
  → usage_ledger に記録（fn, tokens, cost_usd）
  → 設定画面「本日の AI 利用」で集計（※月次化予定）
```

### 外部プロバイダ

| プロバイダ | 用途 | 既定モデル | 設定 |
|-----------|------|-----------|------|
| Anthropic | 分類・要約・問い・チャット・探究・ふりかえり | `claude-sonnet-5` | `ANTHROPIC_MODEL` |
| OpenAI | 探究の見取り図（画像）のみ | `gpt-image-2` | `OPENAI_IMAGE_MODEL`, `OPENAI_IMAGE_QUALITY` |

YouTube 文字起こしは **外部 AI 課金なし**（ライブラリ取得。`fetch-transcript` は ledger 未記録）。

## 2. 単価の前提（2026年7月時点）

### 2.1 Anthropic（テキスト）

アプリ内の概算式（`supabase/functions/_shared/usageLedger.ts`）:

```
cost_usd = (input_tokens × 3 + output_tokens × 15) / 1,000,000
```

| 項目 | 単価 |
|------|------|
| Input | **$3 / 100万トークン** |
| Output | **$15 / 100万トークン** |

これは **Claude Sonnet 系の標準料金**（Sonnet 4 / 4.6 / 5 の標準レート）に合わせている。  
`claude-sonnet-5` は 2026-08-31 まで **$2 / $10** の紹介価格の可能性あり → 実原価は一時的に **約 33% 安** になりうる。プライシング設計時は**標準料金で見積もる**のが安全。

出典: [Anthropic Pricing](https://platform.claude.com/docs/en/about-claude/pricing)

### 2.2 OpenAI（画像 — 見取り図）

`gpt-image-2` は **トークン課金**（枚単価の固定リストではない）。

| トークン種別 | 参考単価 |
|-------------|---------|
| Text input | $5 / 100万 |
| Image output | $30 / 100万 |

OpenAI 公式計算機の **1024×1024 目安**（プロンプト長により変動）:

| Quality | 概算 / 枚 |
|---------|----------|
| low | ~$0.006 |
| **medium**（本番既定） | **~$0.053** |
| high | ~$0.211 |

コード内の固定概算（`openaiImage.ts`）は medium **$0.034** — 公式目安より **やや楽観的**。原価計画は **$0.05〜0.06/枚** を推奨。

出典: [OpenAI Image generation guide](https://developers.openai.com/api/docs/guides/image-generation)

### 2.3 インフラ（参考）

| 項目 | 目安 | 備考 |
|------|------|------|
| Supabase | 無料枠〜 Pro $25/月 | DB・Auth・Edge Functions・Realtime |
| Storage | 見取り図 PNG ~200KB〜1MB/枚 | `exploration-graphic-rec` バケット |
| Push | Expo Push | 無料枠内 |

ユーザーあたりのインフラは、AI 原価が十分小さいうちは **無視できるオーダー**。

## 3. 機能別コスト一覧

`usage_ledger.fn` と設定画面の表示名は `lib/usageLabels.ts` に対応。

### 凡例

- **自動**: メモ保存・分類パイプラインでユーザー承認なし
- **手動**: ユーザーが明示的に実行
- **承認**: 実行前にコスト目安＋ GO（日次上限チェックあり）

概算コストは **典型的な1回あたり**（トークン量はメモ長・スレッド長・探究サイズで大きく変動）。

### 3.1 体験① — メモキャプチャ〜スレッド

| fn | 表示名 | トリガー | 自動/手動 | 典型トークン (in/out) | 概算 $/回 | コード上の予算見積 |
|----|--------|---------|----------|----------------------|----------|------------------|
| `classify-note` | 分類 | メモ作成後 | 自動 | 400 / 80 | **~0.002** | — |
| `summarize-note` | 要約 | learn・動画メモ | 自動 | 600–8,000 / 200–400 | **0.006–0.03** | — |
| `generate-questions` | 問い生成 | 要約後など | 自動 | 1,200 / 150 | **~0.006** | — |
| `generate-questions-more` | 問い追加 | ユーザー操作 | 手動 | 2,000 / 120 | **~0.008** | — |
| `generate-questions-video-fallback` | 動画の問い | 文字起こし失敗時 | 自動 | 800 / 150 | **~0.004** | — |
| `chat-turn-note` | 追記の応答 | 追記送信 | 手動 | 1,500 / 200 | **~0.008** | — |
| `chat-turn-ask` | AIに質問 | 質問送信 | 手動 | 2,000 / 400 | **~0.012** | — |
| `run-research` | 調べる | 調べる GO | 承認 | 3,000–6,000 / 1,000–2,000 | **~0.03–0.05** | $0.04 |
| `run-deepdive` | 深掘り | 深掘り GO | 承認 | 3,000–5,000 / 800–1,500 | **~0.03–0.04** | $0.03 |

**メモ1件の初期パイプライン（参考）**

| メモ種別 | 走る処理 | 概算合計 |
|---------|---------|---------|
| `seed` / `feeling`（短文） | 分類 + 問い1 | **~$0.008** |
| `learn`（テキスト） | 分類 + 要約 + 問い1 | **~$0.014** |
| `learn`（動画・文字起こし成功） | 分類 + 要約（長文）+ 問い1 | **~$0.03–0.08** ※動画尺依存 |
| `task` / `ref` | 分類のみ | **~$0.002** |

動画要約は **入力トークンが支配的**。10分動画（文字起こし ~4,000語）で input ~5,000 tokens → 要約だけ **~$0.02**、30分級では **$0.05+** になりうる。

### 3.2 体験② — 横断（探究・ふりかえり）

| fn | 表示名 | トリガー | 自動/手動 | 典型トークン (in/out) | 概算 $/回 | コード上の予算見積 |
|----|--------|---------|----------|----------------------|----------|------------------|
| `cluster-explorations` | 探究の整理 | 手動（探究タブ） | 手動 | 5,000–25,000 / 2,000–8,000 | **~0.05–0.20** | $0.04 ※実態より低め |
| `generate-exploration-graphic-rec` | 見取り図 | 探究詳細で生成 | 手動 | 4,000–8,000 / 1,500–3,000 | **~$0.04–0.08** | （下記と合算） |
| `generate-exploration-graphic-rec-openai` | 見取り図（画像） | 同上 | 手動 | — | **~$0.05**（medium） | （上記と合算 $0.08） |
| `weekly-review` | ふりかえり | 週次・手動 | 手動 | 6,000–12,000 / 300–600 | **~$0.02–0.04** | $0.02 |

**見取り図 1回の合計**: Claude プロンプト設計 + 画像 ≈ **$0.09–0.13**（medium 画像・中規模探究想定）

`cluster-explorations` は `maxTokens: 8192` で **最もブレが大きい重処理**。問い・メモが溜まるほど input が膨らむ。

## 4. コスト構造の特徴（プライシングへの示唆）

### 4.1 固定コストに近い「毎回」処理

分類・要約・問い生成は **1メモあたり数セント以下**。  
ヘビーユーザーでも「メモを大量に放り込む」だけなら、月 **$1–5** 程度に収まりやすい。

### 4.2 変動が大きい「オプション」処理

| 処理 | なぜ高いか | ユーザー体験上の位置づけ |
|------|-----------|------------------------|
| 調べる / 深掘り | 長い output、コンテキスト多め | 能動的・価値高・頻度低め想定 |
| 探究クラスタ | 全問い・全メモを俯瞰 | 週1回未満？ |
| 見取り図 | **画像 API** が支配的 | 探究ごとに1枚・お土産的 |
| 動画要約 | 文字起こし全文を input | learn 動画ユーザーのみ |

→ **無料枠 = 軽い自動処理まで**、**有料 = エージェント・画像・大量動画** の切り分けが自然。

### 4.3 承認制の意味

`research` / `dig` / `graphic-rec` / `weekly-review` / `cluster` は上限チェックあり。  
現状の日次上限 `DAILY_COST_LIMIT_USD=2` は、見取り図 ~20回/日 相当。**月次プランに移行する際は上限も月次に再設計**（別途 `docs/` または設計メモ参照）。

## 5. 利用シナリオ別 — 体験から逆算した頻度と月間原価

試算は **Sonnet 標準料金・画像 medium ~$0.05/枚**（§3 の単価表）。実測が溜まったら `usage_ledger` で置き換える。

### 5.1 体験から頻度を読む

KOTOI の利用はだいたい次の順で厚くなる。

```
Phase A（最初の2〜4週）
  Capture 中心 → 体験①スレッドをたまに開く
  問いの棚は「溜まってから」
  探究・ふりかえりは触らない or 月1〜2回

Phase B（メモ20本〜）
  気になるスレッドで追記・質問が増える
  調べる／深掘りが月数回
  探究タブで「整理」、ふりかえりが週1 habit に

Phase C（定着）
  探究・見取り図・呼び戻しが価値の中心
  動画 learn が多いと原価のばらつきが最大
```

**体験①（1メモ＝育つスレッド）** で発生する AI:

| ユーザー行動 | 走る処理 | 頻度の目安 |
|-------------|---------|-----------|
| メモを放り込む | 分類（必ず）＋ type 次第で要約・問い | Capture のたび |
| learn 動画 URL | 上記 + 文字起こし（無料）+ 長文要約 | learn の一部 |
| 追記を送る | 接続の問い（あれば） | 戻ったスレッドの ~30% |
| 質問を送る | 回答 + フォロー問い | 戻ったスレッドの ~20% |
| 問いに向き合う | 一言ドラフト | 問いカードの ~10% |
| 調べる / 深掘り GO | エージェント + 新問い | **月1〜10回**（承認制で抑制） |

**体験②（溜まった後の横断）** で発生する AI:

| ユーザー行動 | 走る処理 | 頻度の目安 |
|-------------|---------|-----------|
| 探究タブで整理 | `cluster-explorations` | 月0〜4（メモが溜まってから） |
| 探究詳細で見取り図 | graphic-rec ×2行（Claude + 画像） | 探究あたり0〜1枚 |
| ふりかえりタブ | `weekly-review` | 週0〜1（通知あり） |
| 問いの棚 | AI なし（閲覧のみ） | — |

**メモ type の月間ミックス（参考）**

| ペルソナ | seed | learn | feeling | task/ref | 動画（learn内） |
|---------|------|-------|---------|----------|----------------|
| 断片メモ型 | 多 | 少 | 少 | 少 | ほぼなし |
| スレッド育成型 | 中 | 中 | 少 | 少 | 月1〜2本 |
| 探究型 | 中 | 多 | 少 | 少 | 月2〜4本 |
| ヘビー | 少 | 多 | 中 | 少 | 週1本級 |

### 5.7 プライシングへの読み取り（再掲）

- **中央値は月 $1 未満〜$1.5**（B〜C）— 定額 **¥500〜1,000/月** でも原価余裕は大きい。
- **体験①の自動処理**（分類・要約・問い）は単価が安く、**無料枠に含めやすい**。
- **課金の境界候補**: 調べる／深掘り回数、見取り図枚数、長尺動画、探究整理 — いずれも **能動操作・承認制** と一致。
- **ヘビー尾（D上振れ・全体の10%想定）** だけ従量キャップ or 上位プランで吸収。
- 見取り図1枚 ≒ スレッド対話10回分の原価 → **「探究を深く楽しむ人」向けのプレミアム** に向く。

## 6. アプリ内の計測との対応

### 記録されるもの

| 種類 | 記録方法 | 例 |
|------|---------|-----|
| Anthropic 呼び出し | `recordUsage(fn, input, output)` | 分類、問い、調べる |
| OpenAI 画像 | `recordFlatUsage(fn, flat_usd)` | 見取り図（画像） |

### 記録されないもの

- YouTube 文字起こし取得
- リンクプレビュー取得（`fetch-link-preview`）
- 署名付き URL 発行・Storage 読み取り

### 既知のギャップ

1. **画像コストの固定概算**（$0.034）が公式目安より低い → 原価見積もりは本ドキュメントの表を優先
2. **`cluster-explorations` の予算見積 $0.04** が実態より低い可能性
3. **日次集計** — 月次プラン設計と同時にウィンドウを変更予定
4. **モデル変更**（Haiku 化、Sonnet 5 紹介価格）で原価が一気に変わる

## 7. プライシング検討用チェックリスト

検討時に決めたい項目:

- [ ] **課金単位**: 月額定額 / クレジット制 / 従量キャップ併用
- [ ] **無料枠に含める処理**: 分類・要約・問い1まで？ 動画は？
- [ ] **プレミアム候補**: 見取り図、調べる/深掘り回数、探究クラスタ頻度
- [ ] **上限の見せ方**: 「今月あと $X」vs「見取り図あと N 回」
- [ ] **原価安全率**: API 値上げ・為替・ヘビーユーザー用に **2–3× マージン**
- [ ] **競合参照**: Notion AI / Mem / Reflect 等（機能単位ではなく「問いの質」で差別化）

### ざっくり価格帯の感覚（原価ベース）

§5 ペルソナとの対応:

| ペルソナ | 月間原価 | 定額で取りうる幅（3×マージン + インフラ） |
|---------|---------|----------------------------------------|
| A 断片 | ~$0.25 | 無料枠で十分 |
| B 育成 | ~$0.85 | 無料〜¥500/月 の裏側 |
| C 探究 | ~$1.55 | ¥500〜1,000/月 の裏側 |
| D ヘビー | ~$3.25（上振れ $6〜12） | ¥1,000/月 or 上位プラン |

※ 日本個人向けメモは **¥500–1,500/月** が心理的に読みやすい帯。B〜C が中心なら **粗利は十分取れる**。
