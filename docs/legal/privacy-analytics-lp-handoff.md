## 変更A — §5「取得する情報」に小見出しを追加

**場所**: `### 5.5 利用量・課金` の直後、`### 5.6 端末・アプリ上のローカル情報` の前。

**挿入する本文（そのまま）**:

```markdown
### 5.6 利用状況イベント（Analytics）

- 画面の開閉、メモ作成の有無、問いの棚や今日の問い、課金画面まわりの操作など、機能改善と障害把握のためのイベント記録
- イベント名およびそれに付随する最小限のメタデータ（例: 問いの類型コード、プラン種別、成功／キャンセル等）。**メモ本文・問い本文・メールアドレス・文字起こし等は含めません**
- 第三者の広告・行動分析 SDK（例: PostHog 等の外部 Analytics 製品）は用いず、当方が契約するクラウド（Supabase）上に保存します
```

**注意**: 既存の `5.6` `5.7` は番号を繰り下げてください。

| 旧 | 新 |
|---|---|
| 5.6 端末・アプリ上のローカル情報 | **5.7** 端末・アプリ上のローカル情報 |
| 5.7 取得しない／現状扱わないもの | **5.8** 取得しない／現状扱わないもの |

## 変更B — §6「利用目的」（Analytics 追記・本体）

**場所**: 利用目的の番号リスト。

**現行（サイト）**:

```
1. 本サービスの提供（認証、保存、表示、AI処理、通知）
2. 利用上限・トライアル・有料プランの判定および不正防止
3. 障害対応、セキュリティ、サポート対応
4. サービス改善（プロンプト・分類品質の向上）。学習目的でユーザー本文を第三者の基盤モデル一般学習に無断提供しない方針とします（委託先の標準条件が異なる場合は契約・設定で可能な限り除外し、変更時は本ポリシーを更新します）
5. 法令に基づく対応
```

**差し替え後**:

```
1. 本サービスの提供（認証、保存、表示、AI処理、通知）
2. 利用上限・トライアル・有料プランの判定および不正防止
3. 障害対応、セキュリティ、サポート対応
4. サービス改善（プロンプト・分類品質の向上）。学習目的でユーザー本文を第三者の基盤モデル一般学習に無断提供しない方針とします（委託先の標準条件が異なる場合は契約・設定で可能な限り除外し、変更時は本ポリシーを更新します）
5. 利用状況の把握（Analytics）: 画面の開閉、メモ作成の有無、問い・課金まわりの操作など、機能改善と障害把握のためのイベント記録。メモ本文・問い本文・メールアドレス等は含めません。第三者の広告・行動分析 SDK は用いず、当方のサーバー（Supabase）上に保存します
6. 法令に基づく対応
```

（旧「5. 法令…」は **6.** に繰り下げ）

## 変更D — §10「開示・訂正・利用停止・削除」（アカウント削除導線の更新）

Analytics と同タイミングで反映してください（アプリ内削除が実装済みのため）。

**現行の該当箇条**:

```
- アカウント削除や上記請求は、contact_kotoi@lazywhiz.ioまでご連絡ください。本人確認のうえ対応します。
```

**差し替え後**:

```
- アカウント削除は、アプリの設定から手続できます。ログインできない場合やその他の請求は、contact_kotoi@lazywhiz.io または https://kotoi.art/account-delete からご連絡ください。本人確認のうえ対応します。
```

※ `/account-delete` ページが未公開の場合は、先に account-delete を公開してからこの文言を出すか、一時的にメールのみ残してください。推奨は **account-delete 公開と同時反映**。
