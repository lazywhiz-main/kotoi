## 0. 絶対ルール（デザイン）

**いまのアプリの画面デザインは崩さない。**

| 触ってよい | 触ってはいけない |
|------------|------------------|
| チュートリアル用の**追加レイヤー**（スポット・脈動・短い囁き・一時的な印） | 既存コンポーネントの形・色・余白・タイポの「作り直し」 |
| 既存の強調フックの利用（例: `CaptureComposer` の `emphasized`） | ヒーロー差し替え、別系統のボタン、説明カードの常設 |
| 空状態の**文言**の調整（必要なら） | EmptyState のレイアウト言語を別物にすること |
| ヘッダー info のコピー | タブバー／カード／composer の見た目改変 |

モックでも **下地＝現行 UI の模写**、その上にだけチュートリアル要素を載せる。  
ギャップが出たら、チュートリアル側をアプリに合わせる（アプリをチュートリアルに合わせない）。

---

## 1. ねらい

**読ませない。見せて動かす。**

| やる | やらない |
|------|----------|
| 押してほしいものを光らせる／脈打たせる | スクロール内の説明カード |
| 対象のそばに一言（6〜12字） | 長文の「ここは〜です」 |
| タブの脈動で「次はここ」 | 強制スライドショー |
| 既存 UI の上に載せる | 画面そのものをチュートリアル用に再デザイン |

---

## 2. 流れ（トリガー）

```
ホーム（メモ0）→ 既存 CaptureComposer を emphasized ＋ 短い囁き
  → 「残す」(↑) を指す
  → スレッド: 既存カードのまま、要約／問いに短い印だけ
  → 問いが生まれたら棚タブを脈動
  → 探究（足りない）: 既存 EmptyState 系 ＋ 進捗の数字（追加）
  → 探究（溜まった）: 既存「振り分ける」ボタンを照らす
  → 束のあと: 既存 ExplorationCard を照らして開く
```

閾値 N 案: **3**（クラスタ下限 2 とは分離可）。

---

## 3. 手法（追加レイヤーのみ）

| 手法 | 実装イメージ | 下地 |
|------|----------------|------|
| 脈動／リング | 既存要素を包む | 要素自体は現行スタイル |
| 囁き | absolute の短文 | 画面レイアウトは変えない |
| インライン印 | 「要約」「問い」6〜8字 | SummaryCard / QuestionCard は現行 |
| タブ脈動 | タブアイコン色・opacity | タブ構造は現行 |
| 進捗数字 | Empty 付近に追加 or 文言に含める | 探究の assign UI は現行 |

---

## 4. 既存との接続

| 既存 | 使い方 |
|------|--------|
| `CaptureComposer` `emphasized` / 「ここからはじめよう」 | H0 の本体。追加は囁き程度 |
| `HeaderTitleWithInfo` | 読ませる説明の逃げ場（能動） |
| 探究の振り分けボタン・ヒント | E1 はこれを照らすだけ |
| `EmptyState` | E0 の下地。数字促しは足してもよいが別カード化しない |
