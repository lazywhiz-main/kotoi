## 確定サマリ

- 目的: 呼び戻し／手段: 別角度の新1問
- リズム選択（既定: 週1・朝8時）
- ホーム先頭カード → 開く／残す／スルー
- ふりかえりの再掲呼び戻しとは分離
- 軽処理のみ・usage_ledger 対象

---

## フェーズ案

### S0 — データと設定（土台）

- `user_settings` にリズム・曜日・通知フラグ（名前は実装時に確定）
- 提示中の「今日の問い」を持つテーブル or JSON（残す前は thread_items に入れない）
- スルー／残しのクールダウン用タイムスタンプ

### S1 — 生成 Function

- Edge Function: 材料収集 → JSON 1問（錨必須）
- Zod 検証・言い換え禁止はプロンプトで担保
- cron / スケジュールからユーザー単位で発火（リズム判定）
- スキップ条件（材料不足・クールダウン）

### S2 — ホーム UI

- 「今日の問い」カード（開く／残す／スルー）
- 残す → 錨ノートに question を insert
- 設定画面: 別角度の呼び戻し（リズム選択）

### S3 — 通知

- 到着プッシュ（リズムオン時のみ）
- タップ → ホーム（またはカードフォーカス）

---

## 推奨順

```
S0 → S1 → S2 → S3
```

S2 までで体験検証できる。S3 は実機。
