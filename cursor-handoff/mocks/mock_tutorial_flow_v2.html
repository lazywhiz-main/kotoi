MONDO — チュートリアル流れモック v2

読ませない案内 ＋ 下地は現行アプリのまま。チュートリアルはリング・囁き・短い印・タブ脈動だけ。

絶対ルール: チュートリアルとして追加・強調する要素以外は、いまのアプリデザインを崩さない。 ギャップがあればチュートリアル側をアプリに合わせる。

シーン

各ステップの「追加層」だけがチュートリアル。下地コンポーネントは CaptureComposer / EmptyState / 振り分けボタン等の模写。

既存の emphasized（「ここからはじめよう」）も下地として使う。
説明カード・別系統ヒーロー・独自ステージ UI は置かない。
