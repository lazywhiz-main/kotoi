# 01 — 製品仕様

## 一行
雑多に放り込むと、AIが分類し・要約し・調べ、そして「次の問い」を返す個人用ノート。差別化は**問いの生成**。

## コアループ
```
Capture（放り込む） → Classify（分類） → Branch（memo / video で分岐）
  → Enrich（要約・調査） → Generate Questions（5類型の問い） → Store & Resurface（貯めて再浮上）
```

## 問いの5類型（全生成でこの枠を強制）
| キー | 類型 | 何を問うか |
|---|---|---|
| `dig` | 深掘り | なぜ・どう成り立つか、前提は何か |
| `con` | 接続 | 過去メモ・他領域とどう繋がるか |
| `ref` | 反証 | 本当にそうか、逆はどうか（※UI表示は「反証」。将来「揺さぶり」に変える可能性あり。enum値は`ref`固定） |
| `act` | 行動 | だから何をするか |
| `exp` | 拡張 | もし〜ならどうなるか |

## メモの分類（type）
ドメイン（仕事/私事）ではなく**処理の意図**で分ける。type によって走る処理が変わる。

| type | 中身 | 処理 | 自動/承認 |
|---|---|---|---|
| `seed` | ひらめき・仮説 | 軽い接続＋問い | 自動 |
| `learn` | 記事・動画・知識 | 要約→問い、深い調査は任意 | 要約自動／調査は承認 |
| `task` | やること | 原則スルー（問い生成しない） | — |
| `feeling` | 感情・日記 | 掘り返さない。軽い振り返り問いのみ | 慎重（分析・反証しない） |
| `ref` | 保存だけ | 保存のみ、要求時に処理 | 手動 |

`is_video` はtypeと独立のフラグ。video の場合は文字起こし→要約の前処理が挟まる。多くは `learn`。

## 2つの体験（情報設計の中核）

### 体験① 1メモの中＝育つスレッド（プロダクトの心臓）
1つのルートメモを起点に、下へ概念がぶら下がる1本のスレッド。
- 最初にぶら下がる: AI要約（learn/video）→ AIの問い（5類型）
- ユーザーがチャットで足す: **追記／質問／調べる／深掘り**（意図をボタンで明示）
- 「調べる」「深掘り」→ 裏でエージェント（Edge Function）が動き、**結果がスレッドにぶら下がる**
- 結果はさらに**新しい問い**を生む（ループ）
- どのAIの問いカードからも「調べる／深掘り」で枝を伸ばせる
- ベースはタイムライン、その上に対話が乗る
- 挙動の真実: `mocks/mock_thread_v3.html`

### 体験② 溜まった後＝横断
スレッドが何本も溜まった後にすること。
- **問いの棚**: 未回答の問いを横断で一覧。5類型でフィルタ。押すと元スレッドへ。
- **探究**: 似たメモ・問いが束になって立ち上がるテーマ。統合の一文＋進行度。開くと**問いの地図**（中心=探究、まわり=メモ、外側=類型色の問い）。
- **今週のふりかえり**: 横断サマリー（メモ/問い/回答/探究の数）＋くり返したテーマ＋**呼び戻し**（古い問いを再提示）。
- 挙動の真実: `mocks/mock_accumulate_v1.html`

## ハイブリッド自動化
- 自動: 分類・要約・video文字起こし＋要約・問い生成
- 承認制: web深掘り調査、長尺/高コスト動画、課金の大きい処理。UIに「調べる？」＋コスト目安、GOでバックグラウンド実行→完了通知。
- 日次コスト上限を設け、超えそうなら承認に落とす。

## feeling配慮
`feeling` は分析・調査・反証を**しない**。振り返りの軽い問いのみ、オフ可。感情を増幅しない。

## スコープ
- **MVP（Phase 1）**: Capture / 体験①スレッド / 自動分類・要約・問い生成 / video文字起こし要約
- **Phase 2**: チャット依頼→エージェント（調べる・深掘り） / 体験②（問いの棚・探究・地図・ふりかえり） / 承認フロー・コスト上限
- **やらない（初期）**: 共有・コラボ、複雑な同期、音声/画像入力
